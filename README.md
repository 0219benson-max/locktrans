# LockTrans 鎖定翻譯 — 隱私權政策

本擴充功能（LockTrans 鎖定翻譯）不收集、儲存或傳送任何使用者個人資料。

## 資料使用說明

- 翻譯功能使用 Google Translate 公開服務（translate.googleapis.com），
  僅傳送使用者主動反白選取的文字片段，不包含任何個人識別資訊。
- 使用者在 Popup 中設定的翻譯偏好（語言設定）僅儲存於使用者本機的
  Chrome storage，不會上傳至任何伺服器。
- 本擴充功能不使用 Cookie、不追蹤瀏覽紀錄、不收集位置資訊。

## 第三方服務

本擴充功能使用 Google Translate 公開 API，
該服務適用 Google 的隱私權政策：https://policies.google.com/privacy
